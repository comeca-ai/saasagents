Instale a Mesa dos Agentes no seu GitHub

Cinco passos curtos. Tudo roda no GitHub do seu repositório.

Passo 1 de 5

Qual é o seu repositório?

Pode colar o link do repositório.

Adicione os dois arquivos

Cada botão abre o GitHub com o nome do arquivo já preenchido. Lá, clique no botão verde Commit changes.

1 O workflow O conteúdo já vai preenchido. Criar o arquivo 1
2 O agente O botão copia o conteúdo. No GitHub, clique na área de texto, cole com Ctrl+V (Cmd+V no Mac) e faça o commit. Copiar e criar o arquivo 2

Salve a sua chave de IA

Use uma chave da Anthropic ou da OpenAI. A Mesa reconhece qual é pela própria chave.

Criar chave na Anthropic Criar chave na OpenAI
  1. Abra a tela de secrets do repositório.
  2. Em Name, use este nome: SAASAGENTS_API_KEY
  3. Em Secret, cole a chave e clique em Add secret.
Abrir a tela de secrets

A chave fica guardada só no GitHub, criptografada. Esta página não vê nem guarda a chave.

Teste a conexão

  1. Abra o workflow Mesa dos Agentes.
  2. Clique em Run workflow e depois no botão verde Run workflow.
  3. Em cerca de um minuto aparece Teste de conexão aprovado.
Abrir o workflow

Se der erro, a própria mensagem diz o que corrigir.

Peça a primeira tarefa

Criar a tarefa no GitHub

A tarefa vira uma Issue. A resposta chega como comentário em cerca de um minuto. Para continuar a conversa, comente /agente seguido do novo pedido.

Pronto. A Mesa dos Agentes está instalada.
